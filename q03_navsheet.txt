TERMINAL NAVIGATION PRACTICE SHEET:

1. pwd (Print Working Directory)
   Explanation: Shows the full path of the current directory you are currently working in.
   Example: pwd

2. ls(List) 
   Explanation: Lists all files and folders present inside the current directory.
   Example: ls

3. mkdir (Make Directory)
   Explanation: Creates a new folder/directory with the specified name.
   Example: mkdir practice_folder

4. cd(Change Directory)
   Explanation: Navigates or moves inside a specific folder.
   Example: cd practice_folder

5. cd .. (Move Up/Back)
   Explanation: Moves one step backward out of the current folder into the parent directory.
   Example: cd ..

6. clear (Clear Screen)
   Explanation: Clears all previous text and commands from the terminal sreen for a clean workspace.
   Example: clear
